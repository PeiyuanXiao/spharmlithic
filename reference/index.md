# Package index

## All functions

- [`align_morph_batch()`](https://peiyuanxiao.github.io/spharmlithic/reference/align_morph_batch.md)
  : Batch Lin 2024 alignment for all specimens

- [`align_scar_batch()`](https://peiyuanxiao.github.io/spharmlithic/reference/align_scar_batch.md)
  : Batch SVD alignment for all specimens

- [`check_scars()`](https://peiyuanxiao.github.io/spharmlithic/reference/check_scars.md)
  : Check a scar table before analysis

- [`compare_groups()`](https://peiyuanxiao.github.io/spharmlithic/reference/compare_groups.md)
  : Compare the overall scar patterns of groups of cores

  : Compare groups of cores on single indices

- [`compute_ei()`](https://peiyuanxiao.github.io/spharmlithic/reference/compute_ei.md)
  : Elongation (ER) and Isotropy (IR) ratios from the orientation tensor

- [`compute_spi()`](https://peiyuanxiao.github.io/spharmlithic/reference/compute_spi.md)
  : Scar Pattern Index (Clarkson et al. 2006)

- [`compute_spi_angle()`](https://peiyuanxiao.github.io/spharmlithic/reference/compute_spi_angle.md)
  : Convert SPI to a scar-pattern angle (Clarkson et al. 2006)

  : CPI and PRA for every peripherally exploited core

- [`cpi_pra_per_scar()`](https://peiyuanxiao.github.io/spharmlithic/reference/cpi_pra_per_scar.md)

  : Summarise power spectrum diagnostics by degree

- [`export_alignment_html_lin2024()`](https://peiyuanxiao.github.io/spharmlithic/reference/export_alignment_html_lin2024.md)

- [`export_alignment_html_svd()`](https://peiyuanxiao.github.io/spharmlithic/reference/export_alignment_html_svd.md)
  : Export an interactive SVD alignment HTML page

- [`export_outline_html()`](https://peiyuanxiao.github.io/spharmlithic/reference/export_outline_html.md)
  : Export every core and its outline to an interactive HTML page

- [`export_spharm_html()`](https://peiyuanxiao.github.io/spharmlithic/reference/export_spharm_html.md)
  : Export interactive SPHARM reconstruction viewer as a self-contained
  HTML file
